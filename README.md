# Ping_Pong ⚡ 

A 4-player multi-ball retro arcade Pong game built with **HTML5 Canvas**, **Vanilla JavaScript**, and **Web Audio API**.

## 🎮 Features
* 4 Multi-Ball Chaos: 3 concurrent balls with dynamic speeds and particle trails.
* Active Scoring: Points awarded on every successful paddle deflection.
* Retro Audio: 8-bit sound effects using the Web Audio API.

## 🕹️ Controls
* Move: `Arrow Up` / `Arrow Down` or `W` / `S`
